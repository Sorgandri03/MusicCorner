FPersistentManager
in package
  • Application

FPersistentManager.php : 8

This class manages the persistent storage and retrieval of objects in the database by using the Foundation classes.

It includes CRUD operations and various utility methods for verification and retrieval. Acts as an intermediary between the database layer classes and the control layer classes. Provides methods to create, retrieve, update, and delete objects using corresponding Foundation classes.
