# MusicCorner
### COS’È MUSICCORNER?
MusicCorner è un applicazione web dedicata agli appassionati di musica che vogliono acquistare cd e vinili. Gli utenti possono condividere recensioni sugli articoli acquistati, permettendo ad altri di fare acquisti informati. Inoltre, i venditori possono mettere in vendita i loro prodotti in modo intuitivo, gestendo facilmente il loro inventario e le vendite. Uno stesso articolo può avere più prezzi, a seconda del venditore, offrendo agli utenti la possibilità di scegliere di acquistare dal negozio che preferiscono.
